
# 🍔 GIU Food Truck Management System

A full-stack web application developed as part of the Software Engineering course at the German International University (GIU). The platform enables students to order food from campus food trucks while allowing vendors to manage menus and customer orders through a dedicated dashboard.

---

## Project Overview

The system aims to reduce waiting times on campus by allowing customers to browse food trucks, place orders in advance, and pick up their meals at scheduled times. Food truck owners can manage menus, monitor incoming orders, and update preparation status in real time.

## Features

### Customer

* Register and login
* Browse available food trucks
* Browse menus by category
* Shopping cart management
* Schedule pickup times
* View order history
* Track order status

### Food Truck Owner

* Manage menu items
* Add, edit, and remove products
* View incoming orders
* Update order status
* Manage truck availability
